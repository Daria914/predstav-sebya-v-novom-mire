# Представь себя в Новом мире — исправленная сборка

## Что исправлено
Библиотека `web-txt2img` теперь подключается как npm-зависимость и должна собираться Vite. Это нужно, чтобы Worker генератора размещался на том же домене, что и сайт, вместо попытки загрузить Worker напрямую с `esm.sh`. Браузеры блокируют cross-origin Worker в таком виде.

## Важно
Эту папку нельзя публиковать через Netlify Drop напрямую как готовый сайт: это исходный проект, который сначала нужно собрать. Я не смог запустить `npm install` и проверить сборку в этой среде из-за отсутствия доступа к npm registry, поэтому после подключения к Netlify нужно проверить Deploy log и протестировать генерацию.

## Публикация через GitHub и Netlify
1. Создайте новый репозиторий на GitHub.
2. Загрузите в него все файлы из этой папки (`index.html`, `package.json`, `netlify.toml`, `README.md`).
3. В Netlify выберите **Add new site / Import an existing project**.
4. Подключите этот репозиторий GitHub.
5. Укажите Build command: `npm run build`; Publish directory: `dist`.
   Эти параметры уже записаны в `netlify.toml`, поэтому Netlify обычно заполнит их автоматически.
6. Запустите Deploy site и дождитесь успешной сборки.

## Требования генератора
Модель работает на устройстве посетителя, а не на сервере, поэтому API-ключ не нужен. Нужен совместимый браузер с WebGPU и достаточно памяти/графических ресурсов. Модель SD-Turbo загружается отдельно (около 2–3 ГБ), а генерация на некоторых телефонах может не поддерживаться.

Если сборка завершается ошибкой, откройте Deploys → последний Deploy → Deploy log и сохраните текст ошибки.


## Файлы сборки
Добавлены `package.json`, `netlify.toml` и `vite.config.js`, чтобы Netlify мог собирать проект через Vite. В `index.html` библиотека подключается через npm-пакет `web-txt2img`.

Важно: исправление требует повторной загрузки этих файлов в GitHub и проверки сборки в Netlify. В этой среде нет доступа к npm registry, поэтому я не могу гарантировать, что библиотека успешно соберётся и запустит генерацию на всех устройствах.
